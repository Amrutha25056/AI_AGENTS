# 🤖 AI Agents – A Collection of Intelligent Python Projects

Welcome to **AI_AGENTS**! This repository contains four Python-based projects built to explore intelligent assistants, web application development, and practical problem-solving.

Each project focuses on a different use case, with a simple interface and a Python backend.

## 📂 Projects Included

### 1. 📚 College Library Chatbot
A Python-based library assistant designed to help users interact with library-related information.

**Features**
- Library chatbot functionality
- Book information stored in JSON
- Flask web application
- Automated tests

**Technologies:** Python, Flask, JSON, HTML/CSS

**Folder:** `library chatbot/`

### 2. 🎬 Mini Movie
A web application for organizing and managing a movie library.

**Features**
- Movie library interface
- Create and view movie details
- Database integration
- Responsive web interface

**Technologies:** Python, Flask, SQLite, HTML, CSS, JavaScript

**Folder:** `mini_movie/`

### 3. 📅 Study Plan Agent
A study assistant designed to help users organize their study activities.

**Features**
- Study planning assistant
- Web-based interface
- Python backend
- Automated tests

**Technologies:** Python, Flask, HTML, CSS, JavaScript

**Folder:** `study plan agent/`

### 4. ✈️ Travel Agent
A travel assistant project that works with travel-related information.

**Features**
- Travel information and destination data
- Interactive web interface
- Python backend
- Travel-related data stored in JSON

**Technologies:** Python, Flask, JSON, HTML, CSS, JavaScript

**Folder:** `travel agent/`

## 🚀 Getting Started

### Prerequisites
- Python 3.10 or later
- pip
- Git (optional, for cloning the repository)

### Clone the Repository

```bash
git clone https://github.com/Amrutha25056/AI_AGENTS.git
cd AI_AGENTS
```

### Run a Project

Each project has its own `requirements.txt` file. Open a terminal inside the project folder you want to run.

For example, to run the College Library Chatbot:

```bash
cd "library chatbot"
python -m venv .venv
```

Activate the virtual environment on Windows:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
python app.py
```

Open the local URL displayed in the terminal, usually `http://127.0.0.1:5000`.

**Note:** Each project may have different setup requirements or startup instructions. Check its individual `README.md` before running it.
